# Book Microservice – SOA End Semester Skill Examination

## Project Overview
This project demonstrates a microservices-based Book Management System developed using Spring Boot. It uses service discovery, API Gateway, PostgreSQL database integration, and Docker Desktop for containerization.

## Technologies Used
- Java
- Spring Boot
- Spring Cloud Netflix Eureka
- Spring Cloud API Gateway
- PostgreSQL
- Docker Desktop
- Maven
- REST APIs

## Architecture
- **Book Service:** Handles book-related CRUD operations.
- **Eureka Server:** Provides service registration and discovery.
- **API Gateway:** Routes client requests to the appropriate microservice.
- **PostgreSQL:** Stores book information.
- **Docker Desktop:** Builds and runs application containers.

## Docker Implementation
Docker Desktop is used to build and run the microservices as containers.

The project includes Docker images and containers for running the application components independently.

## Project Objectives
- Implement microservices architecture.
- Configure service discovery using Eureka.
- Route requests through API Gateway.
- Integrate PostgreSQL.
- Containerize applications using Docker.
